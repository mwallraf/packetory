<interfaces>
`lib/hooks/useKeyboardShortcut.ts` (read at 8b2a3b1, used unchanged):
- `useKeyboardShortcut(handlers: { slash?, enter?, escape?, copy? }): void`. The handlers are read from a ref synced after every render, so fresh closures are safe.
- "/": ignored with Ctrl, Meta or Alt; fires only when the target is not editable (INPUT, TEXTAREA or contenteditable; a range input is an INPUT). It calls preventDefault.
- Enter: skipped when `target.closest('button, [role="button"], [role="radio"], a[href], summary')` is non-null. A Radix Switch is a button, so it is skipped. Natively, Enter on a button fires its click, so a focused switch toggles once.
- Escape: skipped when `event.isComposing || event.keyCode === 229`; fires from anywhere, including inputs.
- Copy chord: `(ctrlKey || metaKey) && !shiftKey && !altKey && key.toLowerCase() === "c"`, and only when not editable.

- drafts `lengthDraft`/`lengthError`, `symbolDraft`, `batchDraft`/`batchError`;
