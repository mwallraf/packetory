<objective>
Second vertical slice: bit-level classification. Building on 05-01's page, a valid MAC now also shows its OUI prefix (MAC-04) and labeled badges for U/L addressing (MAC-05), I/G addressing (MAC-06), and — when the locally-administered bit is set — a hedged "Likely randomized (privacy MAC)" badge (MAC-07), each with a one-line plain-language explanation (D-08/D-09). All of it is pure, synchronous, and offline: classification renders in full with zero dependency on the vendor lookup that ships in 05-03, which is exactly what MAC-08 demands.

Purpose: Deliver the bit-level intelligence that is the tool's core value and structurally guarantee (via ordering + a network-free pure function) that classification survives any vendor-lookup failure.
Output: lib/mac/classify.ts (+ tests), extended lib/mac/types.ts, and the classification section wired into MacTool.tsx.
</objective>
