## Phase Goal (MVP user story)

**As a** network engineer, **I want to** enter an IPv4 or IPv6 CIDR and instantly see its full, mathematically-correct subnet breakdown with every field copyable and the result reflected in a shareable URL, **so that** I can get my subnet answer in seconds and hand a teammate a link that reproduces it exactly.

## MVP Slice — what a user can do after this plan

Before: the IPv6 grid is complete but subdivision suggestions are static/absent. After: a user viewing an IPv6 block wider than /64 sees a short row of clickable prefix pills (e.g. `/48`, `/56`, `/64`); clicking one instantly re-runs the tool on the first sub-block at that prefix and updates the shareable URL — no breadcrumb, fully reversible by editing the input.
