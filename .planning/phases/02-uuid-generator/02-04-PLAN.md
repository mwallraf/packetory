<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| in-memory UUID array -> clipboard / downloaded file | Generated values are serialized to the clipboard and to a Blob the browser saves; both are local, author-controlled data. |
| (none network) | Serialization and download are fully in-browser; nothing is sent anywhere. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-06 | Tampering (CSV injection) | lib/uuid/export.ts toCsv | low | accept | The UUID alphabet is hex digits + hyphen only; a value can never begin with `=`,`+`,`@` or contain a comma/quote/newline, so there is no spreadsheet-formula-injection or CSV-structure-injection surface (RESEARCH Don't Hand-Roll). No escaping library is warranted; accepted with rationale. |
| T-02-07 | Denial of Service (resource) | Blob object-URL on repeated Download | low | mitigate | Call `URL.revokeObjectURL` immediately after the synthetic anchor click (Pitfall 3) so repeated downloads do not leak object URLs. |
</threat_model>
