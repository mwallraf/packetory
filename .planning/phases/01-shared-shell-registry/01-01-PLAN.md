## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry -> build machine | Third-party packages installed during scaffold execute arbitrary install scripts (supply-chain surface). |
| browser localStorage -> client theme logic | The stored theme value is client-controllable input read on every load. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-SC | Tampering | npm installs during scaffold | high | mitigate | Blocking-human package-legitimacy checkpoint (Task 1) verifies every package on npmjs.com before install; only packages named in CLAUDE.md's documented stack are installed; no `[SLOP]` package. |
| T-01-02 | Tampering | localStorage theme value | low | mitigate | The pre-hydration script and ThemeProvider validate the stored value against the {light,dark} set before applying it to `<html>`; any other value is ignored, so a poisoned localStorage entry cannot inject an arbitrary class or script. |
| T-01-03 | Information Disclosure | theme persistence mechanism | low | accept | Theme persistence deliberately uses localStorage, not a cookie — no tracking-cookie surface is introduced (supports QUAL-07). No PII stored. |
</threat_model>
