2. `lib/password/crack-time.ts` (D-17):
   - `crackTimeLog10Seconds(bits, guessesPerSecond)` returns `(bits - 1) * Math.log10(2) - Math.log10(guessesPerSecond)`. That is the average case (half the keyspace), in log space so 128-character passwords never overflow.
   - `formatCrackTime(log10Seconds)`:
     - Returns "less than a second" for NaN, for `-Infinity` and for any value below 0.
     - Returns "more than a trillion years" for `+Infinity` and whenever `log10Seconds >= 13 + Math.log10(SECONDS_PER_YEAR)`. That shortcut avoids overflow.
     - Otherwise `const s = roundSig12(10 ** log10Seconds)`, where `roundSig12(x)` is `Number(x.toPrecision(12))`. Return the first match:
       - `s < 60`: floored seconds;
       - `s < 3600`: floored minutes;
       - `s < 86400`: floored hours;
       - `s < SECONDS_PER_YEAR`: floored days.
     - Otherwise `const y = roundSig12(s / SECONDS_PER_YEAR)`. Return:
       - `y >= 1e12`: "more than a trillion years";
       - `y >= 1e9`: floored `y / 1e9` + " billion years";
       - `y >= 1e6`: floored `y / 1e6` + " million years";
       - `y >= 1e3`: floored `y / 1e3` + " thousand years";
       - otherwise floored years.
     - Singular: when the floored count is 1, use "1 second", "1 minute", "1 hour", "1 day" or "1 year". Suffix buckets always say "years" ("1 thousand years").
