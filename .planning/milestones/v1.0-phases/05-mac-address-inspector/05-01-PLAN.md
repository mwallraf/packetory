## Phase Goal (MVP user story)

**As a** network engineer, **I want to** paste or type a MAC address in any common separator format and instantly see it normalized into every variant with one-click copy, **so that** I can hand the address to whichever tool expects a given format (Wireshark colon, Cisco dot, Windows dash, raw) in seconds.
