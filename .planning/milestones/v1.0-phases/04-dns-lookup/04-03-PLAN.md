<objective>
Add the SEO metadata, worked example, FAQ, and FAQPage JSON-LD to the DNS tool page — and, critically,
the D-02 resolver-disclosure item that transparently tells users their lookups are sent to Cloudflare
(primary) and Google (fallback). This completes the established per-tool-page content pattern (unique
metadata + canonical/OG + worked example + genuine FAQ + structured data) that every prior tool page
ships, and gives DNS-09's primary/fallback transparency a plain-language home for the user.

resolvers, grounded in the project's Belgian/EU privacy-first positioning and project-brief §8.2's
sensitivity flag on domain names. The worked example demonstrates DNS-07's display fields (values, TTL,
resolver, duration) with hand-verified constants.

Output: the extended `page.tsx` (metadata + worked example + FAQ + JSON-LD), a new `faq-data.ts`
(faqItems + hand-verified sample constants), the privacy-notice disclosure update, and an SEO E2E test.

Depends on 04-01: this plan extends `page.tsx` (a 04-01 artifact) → Wave 2. It shares no files with
04-02 (which only touches DnsTool.tsx / DnsTool.test.tsx / dns-lookup.spec.ts), so 04-02 and 04-03 run
in parallel within Wave 2.
</objective>
