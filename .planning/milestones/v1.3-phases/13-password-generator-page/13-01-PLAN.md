<interfaces>
From `@/lib/password` (Phase 12 barrel, read 2026-11-11 at 8b2a3b1). Import everything from the barrel, never from a deep path:
- `generateBatch(opts: PasswordOptions, count: number, options?: { fill?: RandomFill }): string[]`. The count is clamped to 1..20. It throws `CryptoUnavailableError` when `globalThis.crypto?.getRandomValues` is missing and `GenerationExhaustedError(attempts)` after `MAX_GENERATION_ATTEMPTS` (10,000) resamples.
- `parseOptions(search: string): ToolOptions`: total, accepts a leading "?", clamps and whitelists.
- `normalizeToolOptions(input: unknown): ToolOptions`.
- `ToolOptions` fields: mode, length, uppercase, lowercase, digits, symbols, symbolSet, avoidLookalikes, words, separator, capitalize, appendNumber, batch.
- Constants: `LENGTH_DEFAULT` 20, `UPPERCASE`, `LOWERCASE`, `DIGITS`, `DEFAULT_SYMBOLS` "!@#$%^&*()-_=+[]{};:,.?", `DEFAULT_OPTIONS` (frozen).
- `RandomFill = (buf: Uint32Array) => Uint32Array`. `randomInt` draws one Uint32 per call and returns `r % n` for small r, so a fill writing the value k makes the next character pool index k.
- Default pool index ranges: uppercase 0-25, lowercase 26-51, digits 52-61, symbols 62-84. `cycleFill([0, 26, 52, 62])` therefore yields "Aa0!" repeated.

From `@/lib/hooks/useCopyToClipboard`: `useCopyToClipboard(revertMs = 2000)` returns `{ copy(value): Promise<void>, copied: boolean, error: boolean, reset(): void }`. `copy` never throws; a rejected write sets `error`.

From `@/app/sitemap`: `SITE_URL = "https://packetory.dev"`.

Island contract this plan creates (later plans extend these exact names):

- `PasswordOutput` props: `{ gen: Generated; heroCopy: CopyState; onRegenerate: () => void }`, where `CopyState = ReturnType<typeof useCopyToClipboard>`.
- Test ids (UI-SPEC): password-skeleton, password-tool (island root, orchestrator decision), password-output-zone, password-hero, password-output, password-copy, password-regenerate, password-error.
