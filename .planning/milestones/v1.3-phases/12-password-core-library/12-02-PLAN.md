<objective>
Prove ROADMAP Phase 12 SC-2 on the CSPRNG primitive that plan 12-01 created, and add batch generation.
- `randomInt` has no modulo bias at its rejection boundaries.
- No fill call can ask for more than 65,536 bytes.
- With Web Crypto absent the library throws a typed error instead of using a weaker source.
- Nothing draws at import.
- `generateBatch` (D-04) produces up to 20 passwords through the same byte-capped seam.

Purpose: these are the guarantees Phase 13 relies on for PWD-07's error state and the SSR-leak guard. PWD-04's "without biasing the distribution" holds only if `randomInt` is unbiased, so this plan carries PWD-04's sampling half.
Output: `generateBatch` in `generate.ts`, an extended `generate.test.ts`, and a new `random.test.ts`. `random.ts` changes only if a proof exposes a defect.

Requirement note: PWD-04 is the only ID Phase 12 owns; this plan proves its unbiased sampler. The PWD-07 user-facing error is claimed by Phase 13.
</objective>
