# Phase 12 Plan 04: Passphrase half of the password library Summary

The vendored, unmodified 7,776-word EFF Large list (generated by a committed script, pinned by two SHA-256 values), a memoized retry-safe lazy loader reachable only through a literal dynamic `import()`, and a synchronous passphrase generator that draws every word and the optional digit through the same rejection-sampled `randomInt`.

**Duration:** about 3 min (2026-11-11T20:51:30Z to 20:54Z). **Tasks:** 3. **Files:** 6 created.

## Accomplishments

- `scripts/generate-eff-wordlist.mjs` downloaded the EFF file and printed raw SHA-256 `addd3553...b903e` and joined SHA-256 `c523ba7b...3675`, matching both pins on the first run, so upstream is unchanged.
- `eff-large.ts` is one payload line plus a 20-line header (source, announcement, retrieval date 2026-11-11, both hashes, CC BY attribution naming both versions, "Changes: none to the words", regenerate command).
- `wordlist.test.ts` (node environment, 24 tests) pins the list five ways and proves the script reproduces the committed module exactly and rejects corrupt input.
- `passphrase.ts` / `passphrase.test.ts` cover separators, capitalize ("T-shirt.Drop-down.Yo-yo"), append number, clamps, rejection redraws, the integrity guard and a 200-run property over real Web Crypto.
- Whole `lib/password` suite: 7 files, 209 tests pass; typecheck clean; `npm run lint` has 0 errors (one pre-existing warning in `lib/mac/vendor.ts`, out of scope).
