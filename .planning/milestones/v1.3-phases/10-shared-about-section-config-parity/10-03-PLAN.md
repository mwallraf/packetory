From lib/config/highlight.ts (pure TS, zero imports, no browser APIs, so it is server-safe):
```ts
export type ConfigProfile = "cisco" | "plain";
export type ConfigTokenKind = "plain" | "comment" | "command" | "keyword" | "interface" | "address" | "number" | "string";
export type ConfigToken = { kind: ConfigTokenKind; text: string };
export function highlightConfig(config: string, profile: ConfigProfile): ConfigToken[][]; // one array per "\n"-split line
```
Comment lines are those whose content starts with "!" or "#"; "description"/"remark" lines tokenize as command + plain + string. The rich-copy HTML uses inline colors with bold for command/keyword and italic for comment; in monochrome mode it drops the colors and keeps that emphasis.
