- INFO-04 e2e uses UUID (regenerate) and DNS (network lookup), the two tools whose Enter action is user-visible or leaves the browser. A positive control proves each shortcut is live, so a pass cannot be vacuous.
- SC-1 structure and SC-2 raw-HTML parity are re-proven on the production build (checker revision, 2026-11-11). Before this revision, `npm run test:e2e:prod` ran only hash-worker.spec.ts, so it could pass without checking any Phase 10 page. The new prod spec reuses 10-05's helper rather than copying it, and lives in 10-06 because 10-06 owns the only prod run (Task 3). That keeps 10-05 off port 3101 and the shared `.next`, and gives the file one owner. playwright.prod.config.ts and hash-worker.spec.ts are not changed.
- CLS is re-measured and reported but not gated here: D-18 (user-approved 2026-11-11) defers the CLAUDE.md "no avoidable CLS" gate to Phase 14, which owns Lighthouse/CLS. The re-measure and the Safari/VoiceOver pass are human checks queued for /gsd-verify-work.
- The 320px per-element check is stricter than the existing wrapper-only check in hash-seo.spec.ts. Task 2 carries the one sanctioned contingency for it; every other check in the gate stays as written.
- The 320px overflow assertions measure the About section, not the whole document (UI E1-overflow is "the About area causes no horizontal page overflow"). A document-level check would also measure each tool island, whose 320px behavior no Phase 10 plan owns: Subnet and Config have no prior page-level 320px assertion, and Subnet 320px no-overflow is a Phase 11 target (SC-4, SUBNET-10). The section's own scrollWidth and its right edge against the viewport prove the About area adds no horizontal overflow: every tool page's main is `w-full` inside the `flex flex-col` body (app/layout.tsx:36), so the section's width is set by the viewport, not by the tool island. The document-level check is kept only for hash, where tests/e2e/hash-layout.spec.ts (INT-03) already asserts `documentElement.scrollWidth <= documentElement.clientWidth` at exactly 320x800 in both color schemes.
