<objective>
Fix the PR #16 CI failure in tests/e2e/hash-layout.spec.ts:24 and drop the end-to-end job from CI.

Root cause (diagnosed and verified by the orchestrator — locked): Linux Chromium rounds Geist Mono glyph advances (about 9.6px up to 10px), so the 128-char SHA-512 and SHA3-512 digests wrap to 6 lines instead of 5 at a 320px viewport. The hash island then measures 2286px against the pinned 2240px skeleton and the layout spec fails on ubuntu CI. Verified inside the official v1.61.1-noble test-runner container: with `[text-rendering:geometricPrecision]` on the digest span, the Linux island measures 2237.9px (identical to macOS) and hash-layout.spec.ts passes. The fix is the class, never the pins.

User decision (locked): remove the whole end-to-end job from .github/workflows/ci.yml to save GitHub Actions minutes; keep typecheck, lint, test and build unchanged.

Purpose: get PR #16 green without weakening the no-CLS skeleton gate (TEXT-01) or the 320px wrapping guarantee (INT-03), while keeping the QUAL-09 merge gate (typecheck/lint/test/build) intact.
Output: one-class change to DigestRow.tsx, a four-job ci.yml, DEPLOY.md aligned with it, and a fully green local gate. Two atomic commits; no push (the orchestrator pushes).
